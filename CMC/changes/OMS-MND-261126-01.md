# OMS-MND-261126-01: Arabic exam, report and certificate for MindProof

Status: BUILT, AI tests passed. Waiting for the owner to deploy the two edge functions and run the staging human test.

## Problem (owner, 2026-11-26)
"I selected Arabic but everything, report, questions, certificate comes in English."

## Root cause
1. Web app: the exam page (university.html / iq-prep.html) ignored the Arabic choice made on the catalog page, and its own "Question language" box always showed English again after each screen refresh (human check, sign-in). Every exam ever started on staging (23 sessions) was saved with language "en"; the 09:37Z sign-in on 2026-11-26 was also sent as "en".
2. The exam screen only switched to right-to-left from a field the server never sends, so even Arabic questions would have been laid out left-to-right with English buttons.
3. Report PDF, certificate PDF and the report email only existed in English. They never read the exam's language, and the PDF fonts had no Arabic letters (Arabic names became "?").

## Fix
- index.html / assessments.html: the "Start exam" link carries the chosen language (?lang=ar or ?lang=en); the catalog remembers the choice.
- university-client.js: language comes from the link or the last choice, the select shows it, and it is remembered for the tab. When Arabic is chosen, the exam screen, review screen, finish dialog, locked result and result page are in Arabic and right-to-left.
- exam-payment and exam-payment-webhook: read the session's language. When it is "ar": the 4-page report, the certificate and the email are in Arabic, right-to-left, with IBM Plex Sans Arabic embedded (no network fetch). Both signatures stay as they are (Arabic signature on the right in the Arabic layout). English output is unchanged. Arabic candidate names now print correctly in both languages.
- No change to the university-challenge edge function or the database: it already stores the language and serves Arabic questions (each domain has 40+ approved Arabic questions for both exams).
