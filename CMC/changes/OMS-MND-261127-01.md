# OMS-MND-261127-01: Free demo ends at the result and never enters the full exam

Status: BUILT on staging (site only, no database change).

## Problem (owner, 2026-11-27 12:53Z to 12:59Z)
Opening the demo led to the 70-question exam. The demo must show 5 questions only, no payment path, show the result, and OK must return to the first demo page. At most 2 demos.

## Root cause
demo.html's "verify your email" button opened the full exam page. After verifying there the visitor was inside the 70-question exam. The demo result also offered "Start the full exam".

## Fix
- demo.html: the verify button opens the exam page with ?demo=<exam>. Result screen shows the score and one OK button, which opens the first demo page again (it shows demos left, or "both demos used"). No link to the full exam or payment from the demo.
- university-client.js: with ?demo=<exam>, a verified visitor is sent straight back to demo.html (after code entry, or on load if already verified). The normal exam page is unchanged.
- Unchanged: 5 questions per demo, 2 demos per verified email per exam, enforced in the database (OMS-MND-261126-10).

## Rollback
Point staging.omsaze.com back to deployment dpl_DLmxeP44iH6BMPZpEZtQTatzAv1w (feature/free-demo a1ac701).
