## What it does
- Column question_bank.english_only (default false).
- Trigger trg_english_only_questions (before insert or update): domain 'linguistic' sets english_only = true; english_only rows get prompt_ar = prompt_en and options_ar = options_en. Applies to every future question whatever tool writes it.
- Riddle BACKFILL1125-CREATIVE-979168b5 marked english_only.
- Check view cmc_check_translated_english_only lists any english_only row whose Arabic differs from English.
