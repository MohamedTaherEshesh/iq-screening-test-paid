# OMS-MND-261126-05: Results register for every exam (admin, Assessment section)

Status: BUILT on DEV, AI tests passed. Waiting for: database change applied, owner deploys admin-analytics, DEV admin test.

## Request (owner, 2026-11-26)
Keep the result of each test and show it in the admin page under Assessment, to build reports for accreditation (local university research partnership, international body such as ANSI/ANAB, independent psychometrics expert).

## Change
- New table `exam_results`: one permanent record per submitted exam, filled automatically by the database when an exam is submitted (no edge function needed). Holds exam, language, name, country, city, age at exam, start and submit time, score, answered, per-domain scores, and per-question outcome (correct / wrong / unanswered, by question code) for later item analysis (difficulty, discrimination, reliability).
- Score fields cannot be edited or deleted (database guard). A failure to record never blocks a candidate's submit.
- All 23 exams already submitted are back-filled.
- Admin page, Assessment: new "Results register" card with totals, average score, median time, valid certificates, search, and CSV download (one column per domain).

## Value added
The raw data the accreditation package will need (pilot data, scores, times) is kept from today, in one place, and cannot be changed.

## Impacted areas
Supabase: new table exam_results, functions record_exam_result, trg_record_exam_result, trg_guard_exam_results, trigger on university_challenge_sessions. Edge function admin-analytics. omsaze-corporate: assets/js/admin.js, assets/css/admin.css.

## Rollback
