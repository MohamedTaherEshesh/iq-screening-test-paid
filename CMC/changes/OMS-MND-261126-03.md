# OMS-MND-261126-03: Exam randomization — no repeats for the same person, shuffled answer positions

Status: BUILT, AI tests passed. Waiting for the owner to deploy university-challenge, then the staging human test.

## Problem (owner, 2026-11-26)
"No exam should come out like another one. Keep randomization in the questions, the type of questions and the numbers. Is this applied?"

## Findings (staging, 2026-11-26)
- Applied: every exam picks 10 random approved questions from each of the 7 sections, and shuffles the question order.
- Missing: the page says previously issued questions are excluded, but the server never did it. The owner's own 11 past exams shared 20 of 70 questions on average, up to 47.
- Missing: answer options were never shuffled; the correct answer was always at the position it was written in.
- Not applied: numbers inside a question are fixed text. Varying them needs question templates (separate, larger change).

## Fix
- university-challenge: questions the candidate already received in earlier exams of the same type are used only when a section has run out of unseen questions.
- university-challenge: answer options are shuffled per exam (seeded by the exam id and question code, so a resumed exam shows the same order). The answer key is saved in the shown positions, so scoring, the report and the certificate need no change. Exams started before this change keep their original order when resumed.
- The function is now self-contained (its own _shared folder), identical to deployed v14 apart from this change.

## Value added
A candidate does not meet the same question twice while unseen questions remain, and answer positions cannot be memorised.
