# OMS-MND-261126-07: Time taken per submitted exam (seconds)

Status: BUILT on DEV, AI tests passed. Waiting for: database change applied, admin-analytics deploy.

## Request (owner, 2026-11-26)
For each submitted exam, know how long it took, for later analysis.

## Change
- exam_results gets duration_seconds (start to submit, capped at the time limit) and time_limit_seconds (6,300 today).
- Exams before 19 Nov 2026 saved the submit time equal to the start time, so their duration is left empty (unknown) rather than 0.
- Admin Results register shows "Time taken" (h:mm:ss) and the median; the CSV has duration_seconds.

## Value added
Answer-time data for the pilot and the psychometric analysis (speed vs score, too-fast attempts).

## Impacted areas
Supabase: exam_results columns, functions exam_duration_seconds, trg_exam_result_duration. admin-analytics, admin.js.

## Rollback
`alter table public.exam_results drop column duration_seconds, drop column time_limit_seconds;` and drop the trigger trg_exam_result_duration.

## Test script
AI (done): admin card shows durations from sample data. PASSED.
After database apply: durations match `submitted_at - started_at` for exams after 19 Nov; earlier ones are empty; a new exam gets a duration on submit.
Note: per-question time is not recorded (the exam page does not send it). That would be a separate change.
